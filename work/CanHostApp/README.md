# 储供系统控制器 V5.4

这是一个 Windows CAN 2.0 上位机初版，聚焦总线连接、帧发送、帧接收和周期发送。

## 储供连接

储供连接通过“选项 → 储供连接…”打开，后台心跳在窗口关闭后继续运行。

协议：

- 连接请求：`ID=01, DLC=2, Data=01 01`
- 设备 SN：`ID=05, DLC=8, Data=01 02 00 00 + 4 字节 SN`
- 心跳发送：`ID=01, DLC=2, Data=01 03`
- 心跳应答：`ID=05, DLC=2, Data=01 03`

测试 SN 为十进制 `2026010001`，即十六进制 `0x78C27591`。

每次发送心跳后等待应答；超过 2 秒没有收到正确应答，则判定连接中断。

## 储供控制

四路电磁阀为可点击控制入口。传感器参数通过主动上报协议实时更新，默认显示 `--`。

气路示意包含：

- 储气罐
- 自锁阀开关状态
- 一级减压阀
- 四路电磁阀比例
- 四路气压传感器
- PTC 加热缓冲腔
- 四路 PT100 温度
- 四路节流器

储供连接的 SN 握手和心跳位于储供控制模块下方，通过“展开连接”按钮打开。

## 传感器主动上报

- 主气压：`ID=0x06, DLC=2, Data=UINT16`
- 支路气压：`ID=0x07, DLC=8, Data=UINT16 × 4`
- 支路温度：`ID=0x08, DLC=8, Data=UINT16 × 4`

每个 UINT16 都是高字节在前、低字节在后。例如 `00 64` 表示原始值 `100`。

## 模块结构

- `Modules/ReceiveFramesModule.cs`：接收帧表格、暂停、导出和清空
- `Controls/FrameTickerControl.cs`：独立单条滚动模块
- `Modules/PlotModule.cs`：气压绘图、坐标配置和清空
- `Models/SensorReportParser.cs`：`0x06/0x07/0x08` 传感器报文解析
- `Modules/SendFramesModule.cs`：帧编辑、单次发送和周期发送
- `MainForm.cs`：只负责菜单、模块布局、CAN 连接和数据分发

后续新增绘图模块时，可以创建新的独立 `UserControl` 并接入主窗口的模块布局，不需要修改现有接收或发送模块。
- CAN 协议 1：优先解析单帧 `01 HH LL`，第二、三字节合成 16 位无符号整数；同时兼容 `01`、高字节、低字节三个独立帧的旧格式

## 运行

打开程序后，通过顶部菜单“选项 → 通信配置”选择适配器、通道、波特率并连接。主界面上方显示接收到的 CAN 帧，下方是帧发送区。

开发环境运行：

```powershell
.\CanHost.VciBridge\build-vci-bridge.cmd
dotnet run --project .\CanHostApp\CanHost.csproj
```

发布到单目录，生成不需要安装 .NET 的 64 位 Windows 程序：

```powershell
dotnet publish .\CanHostApp\CanHost.csproj -c Release -r win-x64 --self-contained true -o .\publish
```

## 适配器连接

### SLCAN

1. 插入 USB-CAN 适配器，在设备管理器确认 COM 端口。
2. 在软件中选择 SLCAN，刷新并选择对应 COM 端口。
3. 大多数 USB CDC 型号的“串口速率”不影响真实 CAN 速率，保持 115200 即可。
4. 选择与对端设备一致的 CAN 波特率，然后连接。

### PEAK PCAN

1. 安装 64 位 PEAK PCAN-Basic 驱动。
2. 选择 PEAK PCAN 和实际使用的 USB 通道。
3. 选择 CAN 波特率后连接。

### 创芯科技 USB-CAN

1. 安装创芯科技 USB_CAN TOOL 和对应 USB 驱动。
2. 软件默认查找 `D:\Program Files (x86)\USB_CAN TOOL\ControlCAN.dll` 和 `C:\Program Files (x86)\USB_CAN TOOL\ControlCAN.dll`。
3. 如果 DLL 位于其他目录，点击界面中的“接口库”文字重新选择。
4. 选择 CAN 1 或 CAN 2 通道，再选择与总线一致的波特率并连接。

创芯科技旧版 `ControlCAN.dll` 是 32 位组件，不能直接加载到 64 位主程序。发布包中的 `CanHost.VciBridge.exe` 专门负责 32 位调用，主程序仍保持 64 位运行。桥接器使用 Windows 自带的 .NET Framework 编译和运行。

## CAN 总线注意事项

- CAN_H 接 CAN_H，CAN_L 接 CAN_L，GND 建议共地。
- 总线两端的终端电阻通常均为 120 Ω，并联后约为 60 Ω。
- CAN 发送需要至少一个其他节点产生 ACK。只接上位机适配器时发送失败或提示 Bus Error 属于正常的物理层现象。
- “已连接”表示适配器已成功打开，并不等价于总线已有人应答。以是否收到 RX 帧或对端反馈为准。

## 当前边界

当前版本针对经典 CAN 2.0，暂未加入 DBC 解析、UDS、CAN FD、定时多帧脚本和数据库信号编辑。
