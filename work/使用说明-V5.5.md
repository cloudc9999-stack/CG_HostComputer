# 储供系统控制器 V5.5

## 本次更新

- 板卡连接与通信配置永久停靠在主窗口左侧，连接和断开按钮使用紧凑尺寸。
- ControlCAN 适配器默认通道为 CAN 1，CAN 波特率默认 1 Mbit/s。
- 左上连接区实时显示适配器连接状态和设备 SN。
- 删除模块自带的拖动栏、最小化按钮和还原按钮，功能窗口统一使用 Windows 原生最小化、最大化和关闭按钮。
- 接收帧、单条信息、发送帧和储供控制均为独立窗口，不再停靠回主窗口内部。
- 接收帧窗口增加“过滤 ID”和“过滤 DLC”选项卡。
- “帮助 > 关于”提供 GitHub 仓库链接，可直接打开并获取最新更新。

## 打开方式

双击“储供系统控制器.exe”。首次连接时，在左上角选择适配器、通道和 CAN 波特率，然后点击“连接设备”。
